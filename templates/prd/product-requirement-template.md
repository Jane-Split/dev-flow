## 一、业务背景 【必填】

| 项目 | 内容 |
|------|------|
| **需求标题** | 一句话描述，不超过 30 字 |
| **业务痛点** | 为什么要做？当前存在什么问题？（2-5 句） |
| **目标用户** | 谁会使用？列出所有角色 |
| **期望上线时间** | YYYY-MM-DD |
| **优先级** | P0(紧急) / P1(高) / P2(中) / P3(低) |

|------|------|
